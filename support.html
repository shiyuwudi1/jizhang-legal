常见问题

我的数据存在哪里？

所有账户、流水、预算、项目和偏好设置都保存在你设备的本地应用目录中，不会上传服务器。简记无需注册账号，也没有云端副本。

换手机或重装 App 后数据还在吗？

不会自动迁移。当前版本未启用 iCloud 同步，数据只存在于原设备。请在换机或卸载前，通过「我的 → 导出中心」导出 CSV / JSON 备份。

如何备份和导出？

打开「我的 → 导出中心」，选择 CSV 或 JSON 导出全部流水。流水页也支持按条件筛选后导出，并可直接分享文件到「文件」App。

如何切换记账成员？

首页左上角的成员胶囊按钮可以切换「全部成员」或某位成员；切换后首页统计、成员对比和筛选会同步变化。

如何设置预算？

「我的 → 预算」→ 右上角「+」，可以按分类、成员、项目或总支出设置预算，并选择月 / 年 / 自定义周期与预警阈值。

打开 App 后没有看到新手教程？

新手教程只在首次启动时自动弹出。之后可以随时从「我的 → 新手教程」重新进入。

支持哪些系统版本？

iOS / iPadOS 26.0 及以上。iPhone 与 iPad 均可使用。

能否多设备同步？

当前版本数据仅保存在本机，暂不支持多设备同步。请使用导出功能自行备份。

如何导入演示数据？

「我的 → 数据 → 导入示例数据」会追加示例账户、成员、项目、预算与近 6 个月流水，不会删除已有数据。

如何彻底删除数据？

删除简记 App 即可清除该设备上的全部本地数据。删除前请先导出备份，删除后无法恢复。
